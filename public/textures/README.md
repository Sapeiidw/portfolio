# Material sources

Locally hosted 1K PBR maps, JPEG recompressed for web delivery:

- Brown Planks 03: https://polyhaven.com/a/brown_planks_03
- Rock Face 03: https://polyhaven.com/a/rock_face_03

Source: Poly Haven. Asset license: CC0 1.0,
https://creativecommons.org/publicdomain/zero/1.0/.
Color, OpenGL normal, and roughness maps are bundled. No asset API or external
texture service is called by the deployed application.
